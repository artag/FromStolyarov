# 2.5. Символы и их коды; текстовые данные

Один и тот же символ всегда представляется одним и тем же числом -
**кодом символа**.

## 2.5.1. Средства работы с символами в Паскале

В Pascal для хранения символов используется тип `char`.

Значения `char`:

- Одиночные символы ('a', '7', '!', ' ', ...)

- Специальные (управляющие символы)
  - `NUL` (0) - при печати ничего не меняется
  - `BEL` (7) - bell, короткий звуковой сигнал
  - `BS` (8) - backspace
  - `HT` (9) - horizontal tabulation
  - `LF` (10) - linefeed, перевод строки
  - `CR` (13) - carriage return, возврат каретки
  - `ESC`
  - `SPC` (32) - пробел

"Кареточная нотация" - способ задания специальных символов от 1 до 26:

- `^A` - символ с кодом 1 (или `#1`)
- `^B` - символ с кодом 2 (или `#2`)
- ...
- `^Z` - символ с кодом 26 (или `#26`)

Пример. Способы записи перевода строки:

```pas
writeln('Hello, world!')
write('Hello, world!', #10)
write('Hello, world!', ^J)
write('Hello, world!'#10)
write('Hello, world!'^J)
```

Преобразование `char->integer` - функция **`ord`**

Преобразование `integer->char` - функция **`chr`**

```pas
var
    c: char;
    n: integer;

n := ord(c);
c := chr(n);
```
