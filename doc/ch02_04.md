# 2.4. Конструирование программ

## 2.4.1. Концепция структурного программирования

Каждая блок-схема предполагает ровно одну точку входа и ровно одну точку
выхода.

Каждый блок может быть "расписан" более детально - *детализация*.

Также несколько блоков могут быть заменены одним блоком - *генерализация*.

Стратегия создания программ - нисходящая пошаговая детализация
(от главной части и ниже).

## 2.4.2. Исключения из правил: операторы выхода

Для одной точки входа может существовать несколько точек выхода - досрочные
выходы из подпрограммы.

В Pascal операторы для досрочного выхода:

- `exit` - выход из подпрограммы

- `halt` - завершение работы программы (обычная форма).
Эквивалентен `halt(0)`.

- `halt(0)` - `halt(255)` - завершение работы программы с возвратом
*кода завершения процесса*.
  - `0` - успешное завершение
  - `1` и так далее (до `255`) - признак ошибки

- `break` - досрочный выход из цикла

- `continue` - досрочное завершение итерации цикла

## 2.4.3. Безусловные переходы

Оператор `goto`, *метки* - места, на которые делаются безусловные переходы.

В Pascal метки описываются в *разделе описания меток*:

```pas
label
    Quit, AllDone, SecondStage;
```

В Pascal при помощи `goto`  нельзя:

- "перепрыгивать" из одной подпрограммы в другую
- "выпрыгивать" из подпрограммы в основную программу
- "запрыгивать" в подрограмму из основной программы

поэтому в Pascal делать метки "глобальными" нет никакого смысла.

Пометить оператор меткой:

```pas
point:
    writeln('Some text');
```

Переход на метку:

```pas
goto point;
```

`goto` **допустимо** использовать в двух случаях:

1. выход из многократно вложенных управляющих конструкций (например циклов)
2. переход из нескольких мест в место, где выполняется высвобождение ресурсов,
очистка.
